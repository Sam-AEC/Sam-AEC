# Contributing

This repository powers the public profile README and its supporting assets.

## Scope

Changes here should improve one of these areas:
- profile README structure or wording
- linked media and badge assets in `assets/`
- documentation that explains how the profile content is maintained

## Guidelines

- Keep pull requests focused and easy to review.
- Prefer small content edits over broad rewrites.
- Optimize images before committing replacements to `assets/`.
- Check links and image references before opening a pull request.
- Avoid adding generated files unless they are part of the published profile experience.

## Pull Request Notes

Include a short summary of what changed and why it improves the profile.
If a change affects visuals, add a screenshot or rendered preview in the PR description.
