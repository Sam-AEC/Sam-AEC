## Flagship: [AEC Model Bridge](https://github.com/Sam-AEC/aec-model-bridge)

**The Revit MCP server that asks first.**

AI assistants such as Claude and Codex read the Revit model you have open. By default, nothing in it changes until a person approves a plan. It is open source: a Python MCP server and a C# Revit add-in.

```text
TOOLS     307, counted from the running server
REVIT     2024 to 2027, one add-in build per year
GATE      AI proposes -> you approve -> Revit changes
PROOF     every executed plan leaves a proof file; a revert goes through the same gate
TESTS     about 3,700 automated; CI does not start Revit
STATUS    1.5.0, pre-release: reads checked in live Revit 2024, writes not yet
```
