# Profile Maintenance

This document explains how the public profile repository is maintained.

## What Lives Here

- `README.md` drives the profile landing page
- `assets/` stores profile visuals used by the README
- `docs/` stores maintenance notes for future updates

## Update Workflow

1. Make focused changes to the profile README or related assets.
2. Keep visuals lightweight and optimized before committing replacements.
3. Verify links, image paths, and section order before merging.
4. Document any non-obvious asset or wording decisions here.

## Content Principles

- Prefer clear, durable wording over trend-driven copy.
- Keep the profile aligned with current BIM, automation, and prefab work.
- Avoid adding decorative assets unless they support the profile narrative.
